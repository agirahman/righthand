# RightHand — Cross-harness capability loader

RightHand capabilities are available under `skills/<capability>/SKILL.md`.

- Mode: skill trigger or persona mention.
- Canonical source of behavior: `profiles/*.md` in this repository.
- Capabilities are reusable modules referenced from each profile's `skills:` field.
- Herdr orchestration: see `README.md` herdr section and `scripts/herdr-spawn.*`.

For interactive `/righthand` switching, use Command Code mod (Command Code only).

This is a pointer file; persona bodies live in `profiles/`.
